# 快速开始

本指南面向第一次使用鲸域的用户，按步骤完成从安装到运行第一个实例。

## 安装

1. 下载最新版 `WhaleRealm-x.x.x-setup.exe`（Windows 10 / 11，x64）。
2. 双击安装包，按向导完成安装。
3. 从开始菜单或桌面快捷方式启动鲸域。

## 收录第一个实例

启动鲸域后，主界面默认进入实例列表：

1. 点击「扫描并收录」自动搜索本机已安装的 DSH 桌面发行体；或点击「手动导入」输入发行体目录。
2. 发现列表中只有通过校验（存在 resources 打包结构、可正常打开）的发行体可以收录，未通过的按钮置灰并带提示。
3. 点击可收录条目后的收录按钮。收录后实例出现在实例列表中，并自动建立初始镜像。

## 新建实例（无需已有发行体）

1. 点击工具栏「新建实例」。
2. 输入实例名称与实例路径（目标文件夹必须为空；可点击「选择文件夹」挑选）。
3. 选择实例类型（官方网页版 / 社区桌面版 / 官方桌面版），选中后自动拉取可用版本，选择版本。
4. 点击确定：软件按真实阶段推进并实时显示进度——核验下载链接与目标目录 → 下载部署（显示百分比）→ 完整性自检 → 收录实例。进度旁会显示 8 位任务标识（完整 ID 悬停可见），供诊断与恢复使用。
5. 创建过程中按钮变为「取消创建」：点击后软件请求主进程按任务所有权回滚清理，收尾期间表单锁定，完成后显示「已取消」。
6. 任一步失败会如实显示错误与失败阶段，表单保留，调整路径或网络后可直接重试；不会误报成功。
7. 注意：官方网页版会自动部署自含 Node.js 运行时与 dsh 依赖（首次创建需下载，约数分钟），创建完成后点「启动」即起本地服务并自动打开浏览器；两类桌面版只能通过「经隔离认证的免安装运行时」自动部署，普通安装器一律禁止执行——某版本未完成隔离认证时，版本列表会如实提示暂不可用，请等待认证版本发布，不要改用安装器安装后再收录。

### 未完成任务的恢复

如果创建中途软件退出或中断，下次启动会弹出「发现未完成的创建任务」：每条任务显示任务标识、目标路径与进程状态。点「确认清理」后，主进程按任务所有权删除该任务的暂存产物，绝不触碰任务之外的文件；进程仍在运行的任务会先给出提示。选「稍后处理」只是收起提醒，下次启动会再次出现。

## 启动与停止

- 点击实例卡片上的「启动」，等待状态圆点变绿（运行中）。
- 点「停止」结束实例，停止后自动建立镜像快照。
- 点「暂停」冻结实例进程树（保留内存状态），「恢复」继续运行；「重启」先停止再启动。

## 常用操作

- 详情：查看隔离路径、端口、运行时信息。
- 端口：修改实例回环端口，冲突时自动更换。
- 修复：集中处理端口冲突、异常退出、镜像差异。
- 删除：仅移除注册（文件保留）或完全删除（移入回收站）。

## 设置

点击窗口右上角设置图标进入设置面板，按外观 / 行为 / 窗口 / 数据 / 语言 / 关于分类：

- 外观：主题、强调色、主界面背景与透明度、样式预设。
- 行为：启动后自动最小化 / 自动关闭、危险操作二次确认、提示开关。
- 数据：API 余额告警阈值、首次使用引导。
- 语言：9 种界面语言，切换即时生效。
- 关于：版本更新、交流群、项目文档（内置使用文档）。

## 托盘

关闭主窗口后鲸域默认驻留托盘。托盘快捷面板支持：运行中实例滚轮切换、停止 / 暂停 / 重启；未启动实例单击展开、双击启动。

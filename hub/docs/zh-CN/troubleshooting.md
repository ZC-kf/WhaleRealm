# 常见问题与错误解决

## 新建实例失败

按提示逐项排查：

1. 「目标文件夹必须为空」：换一个空目录，或清空所选目录后重试。核验阶段不会改动你的目录内容。
2. 「下载链接不可用 / 下载失败」：检查网络后重试；官方网页版的版本目录来自 npm、桌面版来自本机认证清单，网络不通会失败并按任务所有权清回滚暂存产物。
3. 「自检失败」：下载的安装包不完整，重试即可。
4. 「部署能力不足：尚无通过隔离认证的桌面免安装包」：两类桌面版只能部署经隔离认证的免安装运行时，普通安装器一律禁止执行。认证完成前该类型如实显示不可创建；历史安装产物保留原处，可自行运行或经「扫描收录」查看。

## 实例无法启动

按顺序排查：

1. 确认发行体目录未被删除或移动：实例记录的 runtimeRoot 指向源安装目录，删除或替换后无法启动。可删除该实例后重新扫描 / 导入收录。
2. 确认端口可用：在详情页查看端口，点「端口」换一个端口重试。
3. 重启鲸域后重试。

## 启动后窗口不可见

检查系统环境变量是否设置了 `ELECTRON_RUN_AS_NODE`。鲸域启动实例时会显式移除该变量，但如果通过其他方式启动运行体，该变量会让它退化为纯 Node。删除该环境变量后重试。

## 端口冲突

修改端口时鲸域自动检测冲突并换新。若某实例的固定端口被其他软件占用，进入修复页执行「端口 +1」或直接修改端口。

## 实例卡片显示「实例异常」

表示实例停止期间其独立状态（dsh-home 或 workspace）被外部改动，与最后一次停止时的镜像不一致。处理方式：

- 打开修复页查看差异明细（新增 / 修改 / 删除的文件）。
- 确认改动是想要的 → 点「更新镜像」，把当前状态接受为新基线。
- 想丢弃外部改动 → 点「校正还原」，回到镜像状态。
- 也可以从历史镜像（最多 5 份）中选择回撤。

注意：运行中、启动中、暂停中的实例不判定镜像异常，因为会话本身就在写状态。

## 实例状态显示「异常退出」

说明实例进程意外退出。打开修复页执行「重启实例」。如果反复出现，请带着版本、系统与日志信息到交流群或 GitHub Issues 反馈。

## 更新失败

- 检查网络连接后点「检查更新」重试。
- 自动更新失败时可到 Releases 页面手动下载安装包覆盖安装。

## API 余额查询失败

确认已配置 DeepSeek API Key（`%USERPROFILE%\.dsh`）。余额是只读查询，不影响实例运行。

## 退出后还有残留进程

鲸域退出时会回收登记的进程树。若仍发现残留，可用任务管理器结束相关进程，并在反馈中说明复现步骤。

## 反馈流程

反馈问题时请附上：软件版本（设置 - 关于）、系统版本、操作步骤、报错截图或脱敏日志。发送前移除 API Key、Token、账号信息等敏感内容。需要持续跟进的问题建议提交 GitHub Issues，避免被聊天消息淹没。

# 软件介绍

鲸域 · WhaleRealm 是一款面向 DeepSeek Harness 桌面版的本地多实例管理工具。它让多个 DSH 桌面实例在同一台电脑上各自独立、有序并行：每个实例都有互不干扰的运行空间——独立的 DSH_HOME、Electron 用户数据、工作区、端口与单实例锁，不同任务可以同时推进。

## 功能总览

### 多实例管理

- 扫描收录：自动搜索本机已安装的 DSH 桌面发行体，通过校验的发行体可直接收录为实例。
- 手动导入：指定目录收录发行体。
- 新建实例：输入名称、路径与类型版本，自动下载、部署并收录（支持官方网页版、社区桌面版、官方桌面版三类）。
- 卡片 / 列表视图：两种视图切换，卡片展示状态、端口、路径、隔离与 Token 用量。

### 实例操作

- 启动、停止、暂停（冻结进程树）、恢复、重启。
- 打开实例目录、修改端口（冲突自动更换）、查看隔离详情。
- 修复入口：端口冲突、异常退出、镜像差异三类问题集中处理。
- 删除：仅移除注册（文件保留）或完全删除（移入回收站）。

### 强隔离

每个实例独立的 DSH_HOME、Electron 用户数据、工作区、端口与单实例锁，状态根互不共享。

### 镜像快照

实例停止后自动建立镜像；停止期间独立状态被外部改动时比对差异，可选择更新镜像或校正还原，历史镜像最多保留 5 份。

### 全局搜索

主界面搜索栏检索实例与设置项；设置搜索栏定位功能分区，支持键盘上下选择、回车跳转。

### 外观定制

主题（森林 / 海洋 / 莓果 / 石墨）、自定义强调色、主界面背景图与透明度、样式预设、左上角三行文字与底部标语、实例卡片与设置界面背景。

### 托盘与面板

托盘快捷面板：运行中实例滚轮切换，支持停止 / 暂停 / 重启；未启动实例单击展开、双击启动；托盘独立样式与背景图。

### 行为与数据

启动后自动最小化 / 自动关闭、危险操作二次确认、删除与收录时清理桌面快捷方式、操作提示开关、API 余额告警阈值、首次使用引导。

### 多语言

内置 9 种界面语言，切换即时生效。

### 项目文档

设置 - 关于 - 项目文档提供内置使用文档，随界面语言自动切换。

## 下载与安装

- 从 Releases 页面下载最新版 `WhaleRealm-x.x.x-setup.exe`。
- 支持 Windows 10 / 11（x64）。
- 双击安装包按向导安装，安装后从开始菜单或桌面快捷方式启动。

软件使用 `DSH_HUB_ROOT` 环境变量或安装目录中的 `hub-root.txt` 定位本机 DSH 发行体与运行体目录，首次启动时自动解析并持久化。

## 隔离范围与使用限制

隔离范围：每个实例拥有独立的 DSH_HOME、Electron 用户数据、工作区、端口与单实例锁，状态根互不共享。

使用限制：

- 多实例共享的运行体目录不会被删除；删除实例只移除该实例自身的文件与注册，并移入回收站。
- 仅移除注册会保留磁盘文件与镜像，之后仍可手动导入。
- 鲸域是独立开发的社区项目，非 DeepSeek 官方产品。

## 问题反馈与交流

- 反馈问题：附上软件版本、系统版本、操作步骤与报错截图或脱敏日志；发送前移除 API Key、Token、账号信息等敏感内容。
- 提出改进：说明想完成什么、卡在哪里、希望软件怎样帮助。
- 需要持续跟进的问题建议提交 GitHub Issues，避免被聊天消息淹没。

## 开发与贡献

- 技术栈：Electron + React 19 + Vite + TypeScript。
- 依赖安装：`npm install`；构建：`npm run build`；测试：`npm test`；打包：`npm run package:win`（建议配置中国镜像源）。
- 欢迎通过 Issue 反馈问题、通过 Pull Request 参与改进。

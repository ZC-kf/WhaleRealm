## 5. 控件规范

- 一切布尔/多选控件使用**横向开关**（toggle），不使用复选框。
- 主要导航必须有文字标签；隐蔽控件视为功能缺失。
- 顶栏不放状态消息；状态信息放底部状态栏或页内。

## 6. 安全约束（不变）

- 助手不新增特权通道：与人工同 IPC 同权限；执行必须生成计划并经确认；全动作写审计 jsonl；C 档实例只读；删除类操作不在白名单。
- 安装插件/技能必须显式选择目标实例（模态多选），禁止默认装全局 profile。
- 不碰在用实例（3080 / PID 38308）与 `C:\Users\Lenovo\.dsh`。
- 多实例必须经 Hub 启动（注入隔离环境变量），禁止直接双击 exe。
- `.ps1` 纯 ASCII；不改写历史证据快照；打包遇网络超时中止重试、不验证陈旧产物。
- 开源前核实 `rirko/dsh-melody-launcher` 许可证（当前自用先行）。

## 7. 实施顺序（每步重新打包 + CDP 行为验证）

1. 「实例」标签页（列表/卡片/详情/收录）挂入上游骨架；移除我此前另起的 manager surface 分裂。
2. 「启动」页吸收余额卡/轮播/切换整合包/安装状态。
3. 「插件」「技能」页加目标模态与下载队列。
4. 助手右侧抽屉（Codex 形态）+ 批准门 + 审计。
5. 指向式引导覆盖层。
6. 全机发现与收录（注册表支持外部路径）。

## 8. 批判更新（2026-09-24 用户更正）

- 双界面**可接受**：第二界面实测为设置界面，不再列为缺陷；仅要求设置界面与主界面风格统一、入口唯一（删除 WheelchairMode 第二套设置 UI）。
- 首屏（启动器首屏）真实痛点定为四条：① 不识别本机已有 DSH 桌面（无扫描/收录入口）② UI 混乱（同屏两产品概念、卡片曾无样式、无层级与用途说明）③ 无法快捷启动所需桌面（无搜索/收藏/最近启动/一键启动/批量）④ 隔离未知（界面不显示隔离档位/校验状态/路径归属）。
- 对应改法并入第 4 节映射：发现 UI 挂接首屏、首屏每行显示隔离档位与校验状态、快捷启动四件套（搜索/收藏/最近启动/行内一键启动+批量）、Web 运行时降级为可隐藏标签页。

# 安全报告 / Security

## 支持版本 / Supported version

当前发行线：1.0.x。官方桌面运行体尚未认证，不在本版支持范围内。

Current release line: 1.0.x. Uncertified official Desktop runtimes are not supported in this release.

## 报告方式 / Reporting

请勿在公开 Issue 粘贴密钥、个人数据或可直接利用的敏感材料。若仓库 Security 页面提供 **Report a vulnerability**，使用该私密入口；若入口不可用，先提交不含利用细节和敏感信息的联系请求，由维护者安排后续沟通。

Do not post credentials, personal data or sensitive exploit details in public issues. Use **Report a vulnerability** on the Security tab when available. If private reporting is unavailable, open a contact request without exploit details or sensitive data so the maintainer can arrange a private follow-up.

请提供受影响版本、最小复现、影响边界和修复建议。实例隔离用于避免正常使用冲突，并不是对同一操作系统账户下恶意程序的安全隔离。

Include the affected version, minimal reproduction, impact and any suggested fix. Instance isolation prevents ordinary conflicts; it is not an OS security boundary against malicious software under the same account.

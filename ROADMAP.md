# 路线图 / Roadmap

- 官方桌面运行体完成实际 A/B 验收后纳入认证 / Certify official Desktop after real A/B acceptance.
- 独立更新器：退出主程序、安装、数据复核和重启 / Independent updater with exit, installation, data verification and restart.
- 干净 Windows 机器的安装与删除验证 / Clean Windows installation and removal validation.
- 持续维护可信运行体版本与第三方许可材料 / Maintain trusted runtime versions and third-party notices.

本路线图表示后续方向，不表示这些功能已随 1.0.0 交付。 / These are future tasks, not features claimed as delivered in 1.0.0.
